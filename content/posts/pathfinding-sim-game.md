A pathfinding game I built at HSMW for the *Algorithms and Data Structures*
module. The goal: turn pathfinding from pseudocode into something you can see
and play with.

## What it is

A grid where A* and Dijkstra search for a path, visualized so you can watch how
each algorithm explores and compare the two directly.

## Why

Pathfinding is usually taught on paper. Watching the algorithms run makes the
difference between them concrete — which nodes they visit, how the frontier
grows, and why A* reaches the goal faster.

Built with Godot 4.5 in C#. The code lives at
[github.com/heimit0/PathfindingSimGame](https://github.com/heimit0/PathfindingSimGame).
