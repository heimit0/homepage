# Preface
## Why start a homelab
In my oppinion there are only two good reasons to start a homelab. 1. Learning new skills and experimenting in a safe environment. 2. Gain Independence from cloud providers. I fall under the first category.
From the start my goal was to get more comfortable with Linux, Networking and hosting my own services.

## What Equipment am I using for the Lab
My equipment started with me using my pre-existing Fr!tz Box Router and a small MiniPc from MinisForum called the MS-01 equipped with 64gb ram. Software wise im running Proxmox VE as my Hypervisor with multiple mainly linux based VM's.

Recently i was gifted some Unfiy equipment to further expand what i could do with the Homelab.
Now the Fr!tzBox has been repurposed as a Modem with the Unify Cloud Gateway Ultra functioning as the main Router, the Wifi is being provided by a seperate access point and a small 2.5gbe Switch connects all my other devices to the Network.
